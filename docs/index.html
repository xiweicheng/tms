把团队的 沟通、知识、翻译

TMS (Teamwork Management System) 是一款基于频道模式的团队协作平台，集成轻量级任务看板、团队博文 Wiki 与 i18n 国际化翻译管理，响应式设计，开箱即用。

核心能力

一个平台，覆盖团队协作全场景

无需在 Slack、Confluence、翻译工具之间来回切换，TMS 把三件事整合到同一上下文。

💬

频道化实时沟通

基于 WebSocket / STOMP 的实时通讯，频道沟通、一对一私聊、二级话题，消息秒级触达。

@ 提及富文本固定消息桌面通知
📚

团队博文 Wiki

Markdown、富文本、电子表格、思维导图、白板、画图，六种形态自由创作，五级嵌套构建知识树。

版本历史多人协同权限隔离多格式导出
🌐

i18n 翻译管理

专业的多语言翻译项目管理，条目级编辑、历史追溯、批量导入导出，把翻译工程化。

多语言导入导出版本历史条目管理

频道沟通，让讨论直接落地

类似 Slack / BearyChat 的频道化沟通体验，但把任务、日程、甘特图放在同一上下文里。

  • 频道沟通 + 二级话题，按项目 / 主题划分
  • @ 提及、收藏、标签、固定消息，重要信息不淹没
  • 频道任务看板（可拖拽）+ 甘特图，轻量项目管理
  • 日程安排与提醒、待办事项、剪贴板 / 拖拽文件上传
  • 邮件 + 桌面 + Toastr 多渠道通知，自定义皮肤色调

博文 Wiki，知识沉淀有迹可循

类似精简版 Confluence，但更轻更快，支持六种创作形态与完整协作能力。

  • Markdown / 富文本 / 电子表格 / 思维导图 / 白板 / 画图
  • 博文空间 + 父子五级嵌套 + 目录拖拽排序
  • 多人协作编辑（带编辑锁）+ 版本比较与回退
  • 权限管理、点赞、分享、游客访问、评论
  • 导出 PDF / Markdown / HTML / Excel / PNG
  • WebSocket 实时更新通知 + 全量操作审计

i18n 翻译管理，工程化你的多语言

把翻译从散落 Excel 升级为集中管理、可追溯、可协作的工程化流程。

  • 翻译项目管理，按产品 / 模块组织
  • 多语言并行维护，语言管理
  • 条目级编辑 + 历史版本追溯
  • 批量导入导出，对接开发流程
产品亮点

为什么选择 TMS

⚡

实时但不喧闹

WebSocket 实时推送，@ 提醒与固定消息让重要信息浮出水面，分级提醒不打扰。

🔗

知识与沟通同源

频道讨论的结论一键沉淀为博文，博文更新实时通知关注者，知识流动起来。

🎨

多形态创作

不止 Markdown：富文本、表格、思维导图、白板、画图，适配不同知识形态。

🔒

权限精细

用户 + 用户组授权，博文级 + 空间级权限，公开 / 私密 / 游客三态可控。

🤝

协同编辑不冲突

基于 WebSocket 的编辑锁避免覆盖，版本历史 + 一键回退，误删可恢复。

📱

响应式 + 自托管

Bootstrap + Vue.js 响应式设计，数据完全自托管，隐私安全掌握在自己手中。
