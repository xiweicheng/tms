TMS 功能介绍 (Feature Introduction)

TMS (Teamwork Management System) — 一站式团队协作平台，集「实时沟通 + 博文 Wiki + 国际化翻译管理」于一体，响应式设计，开箱即用。

面向产品经理、团队负责人、最终用户，介绍 TMS 的功能亮点、使用场景与价值，帮助你快速判断 TMS 是否适合你的团队。

1. TMS 是什么

TMS 是一款开源的团队协作系统，把团队日常最常用的三件事——聊天沟通、知识沉淀、多语言翻译——整合到一个平台，避免在 Slack、Confluence、翻译工具之间来回切换。

  • 类似 Slack / BearyChat 的频道化实时沟通
  • 类似精简版 Confluence / 蚂蚁笔记 的团队博文 Wiki
  • 专业的 i18n 国际化翻译项目管理

一句话定位：中小团队的一体化协作工作台。

维度 说明
适用团队 5 ~ 200 人的产品 / 研发 / 运营 / 翻译团队
部署方式 本地、Docker、Kubernetes，全部支持
数据自主 全部数据自托管，不依赖第三方 SaaS
开源协议 MIT

2. 三大核心功能

2.1 团队协作沟通

基于 WebSocket 实时通讯，所有消息秒级触达，支持频道化讨论与一对一私聊。

功能清单：

  • 频道沟通（支持二级话题，按项目 / 主题划分）
  • 一对一私聊
  • Markdown 语法支持
  • @ 提及消息（精准通知）
  • 消息收藏与富文本消息目录
  • 频道外链管理
  • 频道甘特图（项目规划可视化）
  • 频道任务看板（可拖拽，轻量项目管理）
  • 频道固定消息（公告 / 规范置顶）
  • 日程安排与提醒
  • 待办事项管理
  • 消息标记表情与标签（快速反馈与分类）
  • 剪贴板 / 拖拽文件上传
  • 从 CSV、Excel 导入 Markdown 表格
  • 邮件、桌面、Toastr 多渠道通知
  • 热键支持（高效操作）
  • 自定义皮肤色调
  • 自定义频道组

价值： 把沟通、任务、日程放在同一频道上下文里，减少上下文切换，让讨论直接落地为待办与计划。

2.2 团队博文 Wiki

类似精简版 Confluence，但更轻、更快，支持多种创作形态。

功能清单：

  • 博文空间（组织管理与权限隔离，按部门 / 项目划分）
  • 多种创作方式：
    • Markdown
    • HTML 富文本
    • 在线电子表格
    • 思维导图
    • 图表工具
    • 白板
  • 基于模板创建博文（支持私有 / 公开模板）
  • 博文目录（支持拖拽排序）与标签
  • 父子级博文（支持五级嵌套，构建知识树）
  • 博文关注、收藏
  • 历史版本（版本比较与一键回退）
  • 博文权限管理、点赞、分享、游客访问
  • 博文评论功能
  • 多人协作编辑（需开启协作权限，带编辑锁）
  • 导出为 PDF、Markdown、HTML、Excel、PNG
  • 基于 WebSocket 的实时更新通知
  • 完整的操作变更历史审计

价值： 知识不再散落在各处，沉淀为可检索、可追溯、可协作的团队资产。

2.3 国际化翻译管理

专业的多语言翻译项目管理工具，适合有 i18n 需求的产品团队。

功能清单：

  • 翻译项目管理（按产品 / 模块组织）
  • 翻译语言管理（多语言并行维护）
  • 翻译导入导出（批量处理）
  • 翻译内容管理（条目级编辑与历史）
  • 翻译条目历史版本

价值： 把翻译从「散落在 Excel / 代码注释」升级为「集中管理、可追溯、可协作」的工程化流程。

3. 其他功能

  • 系统设置 — 站点名称、邮件、皮肤等全局配置
  • 用户管理 — 账号、权限、用户组
  • 用户反馈 — 收集团队成员意见
  • 操作审计 — 全量操作日志可追溯

4. 功能亮点

4.1 实时，但不喧闹

  • WebSocket + STOMP，消息实时推送，无需刷新。
  • @ 提醒、固定消息、标签，让重要信息不被淹没。
  • 桌面通知 + 邮件通知 + Toastr，分级提醒，不打扰。

4.2 知识与沟通同源

  • 频道里讨论的结论，一键沉淀为博文。
  • 博文更新实时通知关注者，知识流动起来。
  • 博文支持五级嵌套 + 目录拖拽，知识结构清晰。

4.3 多形态创作

  • 不止 Markdown：富文本、表格、思维导图、白板、画图，适配不同知识形态。
  • 从 CSV / Excel 导入表格，从 Word（.docx）解析内容。
  • 一键导出 PDF / Markdown / HTML / Excel / PNG，交付无障碍。

4.4 权限精细

  • 用户直接授权 + 用户组批量授权。
  • 博文级权限（可读 / 可编辑）+ 空间级权限。
  • 公开 / 私密 / 游客访问三态可控。

4.5 协同编辑不冲突

  • 基于 WebSocket 的编辑锁，多人协作时避免覆盖。
  • 版本历史 + 一键回退，误删可恢复。
  • 全量操作审计，谁改了什么一目了然。

4.6 响应式，移动端友好

  • Bootstrap + Vue.js 响应式设计，手机 / 平板 / 桌面自适应。
  • 自定义皮肤色调，契合团队品牌。

4.7 部署灵活

  • 本地 / Docker Compose / Kubernetes，三种部署任选。
  • MySQL / PostgreSQL 双数据库支持。
  • 数据完全自托管，隐私可控。

5. 典型使用场景

场景 用法
研发团队日常协作 频道讨论需求 → 任务看板拆解 → 博文沉淀设计文档 → 日程跟进里程碑
产品知识库 用博文空间按产品线组织 PRD、设计稿、会议纪要，五级目录构建知识树
多语言产品团队 翻译项目管理多语言文案，导入导出对接开发流程，历史可追溯
远程团队沟通 频道 + 私聊 + 桌面通知，异地协作如在同一办公室
项目管理 频道甘特图规划周期，任务看板跟踪进度，待办事项分配到人
客户支持 公开博文（游客访问）做帮助文档，内部博文做知识库
跨部门协作 用户组授权 + 空间隔离，既共享又互不干扰

6. 角色价值

对团队负责人

  • 一个平台覆盖沟通 + 知识 + 翻译，降低工具采购与切换成本。
  • 操作审计 + 权限隔离，管理省心、合规可控。
  • 数据自托管，隐私与安全掌握在自己手中。

对产品 / 研发

  • 讨论即文档，减少重复整理。
  • 多形态创作，适配 PRD / 设计 / 技术文档不同需求。
  • 一键导出多格式，交付与评审顺畅。

对运营 / 翻译

  • 翻译项目集中管理，告别散乱 Excel。
  • 历史版本可追溯，避免误改。
  • 多人协作，分工明确。

对所有成员

  • 实时沟通 + 移动端响应式，随时随地协作。
  • @ 提醒 + 待办 + 日程，不遗漏重要事项。
  • 收藏 + 关注 + 标签，个人知识管理井井有条。

8. 快速开始

8.1 Docker 一键启动

git clone https://github.com/xiweicheng/tms.git
cd tms
docker-compose up -d

访问 http://localhost:8090/ 即可使用。

8.2 本地开发

详见 TECHNICAL_DOC.md 第 15 章。简言之：配好数据库 → 改 application-dev.properties → 运行 Application.java → 访问 http://localhost/。

8.3 生产部署

支持 Tomcat War 部署、Docker Compose、Kubernetes 三种方式，详见 TECHNICAL_DOC.md 第 12 章。
